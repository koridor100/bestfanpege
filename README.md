# КОРИДОР — фан-хаб Doors

Одностраничный фан-сайт по игре Doors: кейсы со свечами, статистика забегов, форум и калькулятор ранга.

## ⚠️ Что нужно знать про хранение данных

Файл использует `window.storage.get/set(...)` — это API, доступное **только внутри Claude-артефактов**. Но в коде уже есть встроенный полифилл (в начале `<script>`): если `window.storage` не существует, скрипт сам подменяет его на обёртку над `localStorage`. Поэтому **на GitHub Pages сайт заработает без правок** — кейсы, ежедневный сбор свечей, статистика забегов, форум и калькулятор ранга будут сохранять данные.

Единственный нюанс: параметр `shared: true` (используется для форума и лидерборда) в полифилле тоже пишется в `localStorage` конкретного браузера. Это значит:

- у **одного и того же человека** форум/лидерборд сохранятся между визитами;
- но между **разными посетителями сайта** данные общими не станут — каждый увидит только свои собственные записи, а не записи других людей.

Если нужно, чтобы форум и лидерборд были по-настоящему общими для всех посетителей, потребуется внешний бэкенд/база данных (например, Firebase или Supabase), потому что GitHub Pages отдаёт только статические файлы и сам по себе ничего не хранит. Скажите, если нужна помощь с этим — могу подключить.

## Деплой на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `doors-hub`).
2. Переименуйте файл в `index.html` и загрузите его в корень репозитория (через веб-интерфейс GitHub — кнопка **Add file → Upload files**, либо через git):

   ```bash
   git init
   git add index.html README.md
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<название-репо>.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
5. Нажмите **Save** и подождите 1–2 минуты.
6. Сайт появится по адресу:

   ```
   https://<ваш-логин>.github.io/<название-репо>/
   ```

Готово — страница будет доступна всем по этой ссылке.
